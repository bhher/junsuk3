# Flow Board — 2026년 11월 11일

React + Vite로 만든 칸반 보드입니다. 화면 제목은 **Flow**이고, 문구는 “드래그로 작업 흐름을 시각화하세요”입니다.

## 구성

- 열 4개: 아이디어, 오늘, 진행중, 완료
- 각 열에 색과 카드 개수가 표시됩니다.
- 처음 들어 있는 카드는 열마다 1장입니다.
  - 아이디어: 프로젝트 기획서 작성
  - 오늘: 회의 준비 자료 정리
  - 진행중: React 학습 노트 정리
  - 완료: 이메일 답장하기

## 지금 동작하는 것

- **카드 추가.** 열의 `+ 카드추가`를 누르면 입력창이 열리고, 포커스가 들어갑니다. 내용을 입력한 뒤 `추가`하면 해당 열에 카드가 붙고, `취소`나 Escape로 닫힙니다. 빈 내용은 저장되지 않습니다.

## 화면만 있고 동작은 없는 것

- 카드의 삭제 버튼
- 카드 내용 수정 (수정용 스타일만 있음)

데이터는 화면 상태(`useState`)에만 있고, 새로고침하면 처음 카드로 돌아갑니다.

## 카드 드래그에 더 필요한 것

잡고 놓는 흐름은 `Card`, `Column`, `KanbanBoard`, `App`에 이미 연결되어 있다. 카드에는 `draggable`이 있고, 시작·종료·열 위 이동·놓기가 나뉘어 있으며, `moveCard`가 카드의 열을 바꾸도록 되어 있다. 다만 아래 세 곳이 어긋나서 다른 열로 옮겨지지 않는다.

- `KanbanBoard`에서 열 위에 올렸을 때 `handleDragOver(e, column.id)`로 넘겨야 한다. 지금은 `e. colum.id`라서 이벤트와 열 id가 분리되지 않고, `colum`이라는 이름도 없다.
- 같은 파일에서 놓았을 때 `handleDrop(e, column.id)`로 넘겨야 한다. 지금은 `e.column.id`라서 이벤트 객체에서 열 id를 찾는다.
- `App`의 `moveCard`는 기존 필드인 `columnId`를 바꿔야 한다. 지금은 `columId`로 저장해서, 카드를 걸러 보여주는 `columnId`는 그대로다.

출발 열의 흐림 표시도 `KanbanBoard`에서 `draggedCard.columnId`와 비교해야 한다. 지금은 `columId`라서 드래그 중인 열에 `dragging`이 붙지 않는다.
